🧠 MAPA MENTAL: ECOSISTEMA DESARROLLO WEB 2026

1. Infraestructura y Entrega: CDN

Definición: Red de servidores distribuidos geográficamente que trabajan juntos para proporcionar una entrega rápida de contenido de Internet.

Función: Reduce la latencia al servir archivos desde el servidor más cercano al usuario.

Ejemplos

  • Cloudflare
  • Akamai
  • Amazon CloudFront
  • Google Cloud CDN

2. Estructura de Trabajo: Frameworks

Conjunto estandarizado de conceptos, prácticas y herramientas para resolver problemas comunes en desarrollo.

Diferencia con Librería

  • Librería: Tú llamas a la librería cuando la necesitas (ej: jQuery, Axios).
  • Framework: El framework controla la estructura y ejecuta tu código (Angular, Django).

3. Frameworks JavaScript (Frontend)

  • React: Basado en componentes y enorme ecosistema.
  • Vue.js: Progresivo y fácil de aprender.
  • Angular: Framework empresarial mantenido por Google.
  • Next.js: Estándar actual con Server Side Rendering.

Frameworks CSS (Diseño)

  • Tailwind CSS: Utilidades directamente en HTML.
  • Bootstrap: Componentes listos para usar.
  • Bulma: Basado en Flexbox y sin JavaScript.

Frameworks Python (Backend)

  • Django: Incluye autenticación, admin y ORM.
  • Flask: Micro-framework ligero.
  • FastAPI: Asíncrono y muy rápido para APIs.
